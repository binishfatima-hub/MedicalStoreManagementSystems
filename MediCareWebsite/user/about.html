About MediCare

A simple, complete medical store management system.

What is MediCare?

MediCare is a Medical Store Management System built as a college project. It has two separate parts that share one MySQL database.

👤

User Panel

Customers register, browse the medicine stock, add medicines to a cart, place an order and get a printable GST bill.

🔑

Admin Panel

The store owner adds, edits and deletes medicines, updates stock, manages users and reads the stock and sales reports.

How it is built

Three simple layers, nothing hidden.

Layer Technology What it does
Front end HTML, CSS, JavaScript The pages you are looking at right now.
Back end Java, Spring Boot (REST API) Checks every request and does the calculations.
Database MySQL Stores admins, users, medicines and orders. Nothing on this website is dummy data.

Store Policies

Please read before ordering.

💰

GST 5%

Every bill includes 5% GST on medicines.

📅

Expiry Checked

Expired medicines can never be added to a cart.

📦

Live Stock

Stock reduces the moment your order is placed.

🚫

No Returns

Medicines once sold cannot be returned.
